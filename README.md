# Política de Privacidade — Hermes Metricas

Última atualização: 12/11/2026

O Hermes Metricas é uma ferramenta de uso pessoal do Dr. Thiago Tagliari. Ela consulta, em modo somente leitura, as métricas de desempenho do canal de YouTube @drthiagotagliari, de propriedade do próprio titular, para gerar relatórios internos de desempenho de conteúdo.

## Dados acessados

Estatísticas do canal do próprio titular, obtidas pela YouTube Analytics API e pela YouTube Data API com permissões somente leitura: visualizações, tempo de exibição, retenção de audiência, origens de tráfego e títulos de vídeos.

## Como os dados são usados

Apenas para gerar relatórios internos sobre o desempenho do conteúdo. O aplicativo não acessa dados de pacientes e não publica, altera nem apaga nenhum conteúdo.

## Armazenamento e compartilhamento

Os dados e as credenciais ficam em servidor pessoal do titular. Não são vendidos, compartilhados nem transferidos a terceiros. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

## Revogação de acesso e exclusão

O acesso pode ser revogado a qualquer momento em https://myaccount.google.com/permissions e os dados armazenados podem ser excluídos a pedido.
